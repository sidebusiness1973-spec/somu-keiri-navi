# 総務経理ナビ

従業員・経費・給与の試算・契約情報を、端末内で整理するiOSアプリです。

## 主な機能
- 今月の給与概算・経費・従業員数を確認できるホーム
- 従業員情報の登録・編集・削除
- 月給・時給の支給予定額の試算と保存
- 経費の登録・月別表示・検索・編集・削除
- 契約の基本情報を下書きとして保存

給与は概算です。税金・社会保険料の自動計算、契約書本文・PDFの生成、請求書管理には対応していません。クラウド同期・アプリ内バックアップ・エクスポートはありません。

## 料金
従業員・経費・給与記録・契約情報は、それぞれ10件まで無料です。月額600円・年額6,000円（日本）の自動更新プランで登録件数の制限を解除します。月額と年額の機能は同じです。有効期間終了後も保存済み記録を閲覧・編集・削除できます。実際の価格・条件はAppleの購入画面で確認してください。

## 公開状況
App Storeへの公開準備中です。公開済みのアプリではありません。

## 開発用ファイル
添付のSomuKeiriNavi-source.zipを展開し、SomuKeiriNavi.xcodeprojをXcodeで開きます。iOS 17以降が対象です。署名には開発者アカウントが必要です。

給与計算の15項目の検証が成功しています。実iPhoneで基本操作、経費10件の境界・既存記録の編集、月額・年額の購入・復元・再起動後の継続・期限終了の3つのUIテストが成功しています。購入テストはStoreKitのローカルテストで、実課金はありません。バージョン1.0（ビルド2）のアーカイブ・App Store Connectへのアップロードと処理が完了しています。審査提出を準備中です。

開発用のSomuKeiriNavi-Previewスキームは、架空のサンプルをメモリ内で表示し、保存済みデータを変更しません。Releaseビルドではサンプル表示とUIテストの起動引数を無効にしています。StoreKitの設定ファイルはテストターゲットにだけ含めています。
